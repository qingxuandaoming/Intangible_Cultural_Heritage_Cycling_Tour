骑行装备数据分析系统（灵境行者）- 使用说明
================================================

【快速开始】
  双击"启动系统.exe"，等待启动器窗口显示全部服务就绪（首次运行会自动
  初始化数据库，约需 1-2 分钟，请耐心等待），浏览器将自动打开系统页面。

【访问地址】
  系统页面（前端）:  http://localhost:5000
  Java 后端 API:    http://localhost:8080/api
  Python 后端 API:  http://localhost:5000/api

【首次运行说明】
  1. 启动器会优先探测本机已安装的 MySQL/MariaDB（端口 3306/3307）；
     若本机没有数据库，将自动启动内置的 MariaDB（端口 33306）。
  2. 首次启动会自动创建 ljxz 数据库并导入初始数据（含演示用户）。
  3. 数据保存在 data\mysql 目录下，请勿随意删除。

【演示账号】
  用户名: cyclist1@ljxz.com    密码: password

【注意事项】
  1. 请勿提前关闭启动器窗口，关闭后所有服务将自动停止。
  2. 若端口 3306/5000/8080 被占用，请先关闭占用端口的程序。
  3. 需要 Chrome/Chromium 浏览器（爬虫功能依赖，其余功能不依赖）。

【系统要求】
  - Windows 10/11 64 位
  - 内存 >= 4GB（内置数据库 + 双后端同时运行）
  - 磁盘空间 >= 1.5GB
